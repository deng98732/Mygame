# 🐺 狼人杀网页游戏 (Werewolf Game)

一个精美的狼人杀在线多人游戏，采用日式/二次元美学设计。

## 🎮 功能特性

- ✅ 用户注册/登录系统
- ✅ 房间创建和加入
- ✅ 完整的游戏逻辑（白天投票、夜晚身份验证）
- ✅ 实时聊天和通知
- ✅ 日式/二次元风格UI
- ✅ WebSocket 实时通信

## 🛠 技术栈

**前端：**
- React 18
- Tailwind CSS
- WebSocket
- Axios

**后端：**
- Node.js + Express
- Socket.io
- MongoDB
- JWT 认证

## 📁 项目结构

```
Mygame/
├── frontend/          # React 前端
├── backend/           # Node.js 后端
├── docs/              # 文档
└── README.md
```

## 🚀 快速开始

### 前端开发
```bash
cd frontend
npm install
npm start
```

### 后端开发
```bash
cd backend
npm install
npm run dev
```
